# EUROPEAN CAREER STRATEGY

## Objective

Graduate with both a degree and enough practical evidence to enter an engineering job quickly.

## University Year 1

Build:
- programming
- algorithms/data structures
- Linux
- Git
- networking
- SQL

Outside university:
- Python
- backend foundations
- Linux labs

Target: engineering foundation.

## University Year 2

Build:
- backend/API development
- Docker
- cloud fundamentals
- CI/CD
- security basics

Start applying for internships and working-student roles.

Target internship areas:
- software engineering
- backend engineering
- cloud
- infrastructure
- platform engineering
- SRE
- systems engineering

## University Year 3

Build:
- AWS
- Terraform
- Kubernetes
- observability
- security
- production-style projects

Get a second/stronger internship or working-student position.

Target: graduate with evidence of real team experience.

## First full-time role

Preferred roles:
- Junior Cloud Engineer
- Junior DevOps Engineer
- Cloud Engineer
- Infrastructure Engineer
- Platform Engineer
- SRE
- Systems Engineer
- Backend/Software Engineer with infrastructure exposure
- Production/Cloud Support Engineer if it has a real engineering path

Do not reject a good role because the title does not say DevOps.

## Year 1 professional experience

Objective: learn production.

Learn:
- code review
- CI/CD
- incident response
- monitoring
- deployment
- infrastructure changes
- security
- team communication
- documentation

Career transition: Junior → Independent.

## Year 2

Objective: ownership.

Increase:
- service ownership
- automation
- architecture participation
- reliability work
- cloud depth
- cost optimization
- security

Career transition: Independent Engineer.

## Year 3

Objective: specialization + compensation.

Increase:
- production complexity
- system ownership
- Kubernetes/cloud architecture
- observability
- reliability
- disaster recovery
- security

Career transition: strong mid-level trajectory.

## What counts as useful 3-year experience

Strongest:
- full-time production engineering
- cloud/infrastructure/platform/SRE/backend with significant infrastructure ownership

Weaker:
- mostly low-value website work
- repetitive non-engineering support
- tutorial projects

## Professional evidence archive

For every job keep:
- employment dates
- title
- responsibilities
- technologies
- systems owned
- projects
- measurable impact
- promotions
- salary records
- experience letters
- manager/reference information

Document quantifiable outcomes.

Bad CV bullet:
"Managed AWS."

Better:
"Automated deployment infrastructure with Terraform and reduced manual deployment work from X to Y."
