# JAPANESE SELF-STUDY PLAN

## Role

Japanese is optional in the current Bangladesh stage when time is limited, but it becomes strategically important for the Japan career phase.

## Long-term ladder

Kana → N5 → N4 → N3 → N2 → N1/business Japanese.

Do not treat JLPT as the whole language.

## Current Bangladesh rule

IT comes first.

Japanese target while busy:
20–30 minutes/day.

On overloaded days:
0 minutes is acceptable.

Do not let Japanese destroy the core technical track.

## Free-resource stack

Use a small stable set rather than a giant collection:
- Irodori
- Tae Kim or another coherent grammar reference
- Anki for spaced repetition
- Tadoku for graded reading
- comprehensible Japanese listening resources

Later add Yomitan when reading longer native material becomes useful.

## JLPT strategy

For each level:
1. learn grammar/core vocabulary
2. read graded material
3. listen daily
4. practice kanji through context + SRS
5. do JLPT-style exercises
6. take timed mock tests
7. review every error

## Actual-language strategy

After N3, increasingly consume native media and text.

From N2 onward, add:
- workplace vocabulary
- technical vocabulary
- business writing
- meetings
- professional etiquette

## What success means

JLPT score + actual comprehension + actual communication.

Passing N1 is useful evidence; it is not proof of native-like workplace fluency.
