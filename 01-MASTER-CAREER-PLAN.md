# MASTER CAREER PLAN

## 1. End goal

Become a highly employable international Cloud/DevOps/SRE/Platform-oriented engineer, use a European Bachelor's plus real European professional experience as the bridge to Japan, then pursue Japanese PR through the Highly Skilled Professional framework.

Target age: PR before 29, with ~27–28 preferred when realistically achievable.

## 2. Career identity progression

Student → Engineering Intern → Junior Software/Cloud Engineer → Cloud/DevOps Engineer → Mid-level Cloud/SRE/Platform Engineer → Japanese Cloud/DevOps/SRE/Platform Engineer → senior trajectory → AI Systems Integration / Staff / Architecture direction.

Titles can vary. Capability matters more than title.

## 3. What the European phase must accomplish

The Bachelor's is not the whole goal. Europe must provide three outputs:

1. Relevant degree.
2. Internship/working-student experience.
3. Full-time professional engineering experience, minimum target 3 years.

## 4. What the Japan phase must accomplish

1. Obtain a suitable professional IT role.
2. Keep lawful residence and work status.
3. Maintain/build a strong HSP profile.
4. Target 80+ points as the preferred strategic buffer.
5. Build a clean documentary record.
6. Apply for PR only when the actual current legal requirements are satisfied.

## 5. Career architecture

Software/CS fundamentals
→ operating systems and Linux
→ networking
→ databases and backend
→ containers
→ cloud
→ infrastructure as code
→ CI/CD
→ observability
→ security
→ Kubernetes
→ production ownership
→ specialization.

## 6. The main strategic principle

Do not optimize for a single country, certificate, technology or salary number.

Optimize for portable human capital:

relevant degree + real production experience + strong engineering fundamentals + English + Japanese + increasing compensation.

## 7. Things this plan does NOT depend on

- Becoming a famous freelancer.
- Collecting many certificates.
- Becoming a frontend specialist.
- Learning every new technology.
- Studying Japanese at the expense of core technical development.
- A single named employer.
- A single named European country.

## 8. Major checkpoints

Age 19–20: Europe admission and foundation.
Age 20–22/23: degree + internship + technical portfolio.
Age 22–26: European full-time IT career.
Age 25–27: Japan applications and transition.
Age 26–28+: HSP/PR strategy, subject to actual eligibility.

## 9. Failure modes

### Failure A: endless learning
Fix: projects and gates.

### Failure B: certificate collecting
Fix: prioritize skill, proof and experience.

### Failure C: too much frontend
Fix: learn enough web/backend to understand applications, then shift toward systems/cloud.

### Failure D: Kubernetes too early
Fix: Linux/networking/backend/Docker/cloud first.

### Failure E: freelancing becomes the career
Fix: use freelancing as optional income and evidence; European employment remains the main experience engine.

### Failure F: immigration becomes the whole career
Fix: build a career that naturally scores well rather than gaming points with weak skills.
