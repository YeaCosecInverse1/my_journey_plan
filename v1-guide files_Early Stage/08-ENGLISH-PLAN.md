# ENGLISH + IELTS PLAN

## Priority

English is a required support track because it helps with IELTS, university admission, technical learning, internships, interviews and international work.

## Current state

The user is already attending IELTS coaching. Do not duplicate it with an enormous second curriculum.

## Goal stack

1. IELTS competence.
2. Academic English.
3. Professional communication.
4. Engineering English.

## Engineering English checklist

You should be able to:
- read technical documentation efficiently
- write a GitHub README
- write a bug report
- write an issue
- explain architecture
- describe an incident
- participate in technical meetings
- answer technical interview questions
- write professional emails
- present a project

## Daily integration

Use IT as English practice:
- read documentation in English
- write project notes in English
- write commit messages in English
- explain what you built aloud in English
- watch technical lectures in English

## Time allocation

Let IELTS coaching remain the structured English component.

Outside coaching: roughly 30–60 minutes/day when practical.

Do not steal large blocks from the main IT track unless IELTS has an imminent deadline.

## Self-test

Once a week choose a technical topic and explain it in English for 5–10 minutes without reading notes.

Once a month write a 300–500 word technical explanation and revise it for clarity.
