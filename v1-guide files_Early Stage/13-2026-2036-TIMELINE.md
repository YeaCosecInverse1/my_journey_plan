# 2026–2036 MASTER TIMELINE

## 2026–2027 | Age 18–19

Bangladesh.

Main:
- HSC complete
- technical foundations
- IELTS/English
- European university research/applications
- Japanese habit if time allows

Technical target:
Computer + Linux + Git + Python + networking basics.

## 2027–2028 | Age 19–20

Europe Year 1 if admitted.

University foundation + Linux + programming + Git + networking + SQL.

Japanese target: N4 trajectory.

## 2028–2029 | Age 20–21

Europe Year 2.

Backend + Docker + cloud fundamentals + internship/working-student.

Japanese target: N3 trajectory.

## 2029–2030 | Age 21–22

Europe Year 3.

AWS + Terraform + CI/CD + observability/security + stronger internship/working-student.

Japanese target: N2 trajectory.

## 2030–2031 | Age 22–23

Graduate and enter European IT employment.

Target roles:
Cloud / DevOps / SRE / Platform / Infrastructure / Backend with infrastructure exposure.

## 2031–2032 | Age 23–24

Professional Year 1.

Move from junior to independent.

Priority: production systems, incidents, deployments, cloud, Linux, automation.

## 2032–2033 | Age 24–25

Professional Year 2.

Increase ownership, specialization and compensation.

Begin serious Japanese-employer research.

Japanese target: N2/N1 trajectory.

## 2033–2034 | Age 25–26

Professional Year 3.

Strong Cloud/DevOps/SRE/Platform specialization.

Prepare Japan applications.

Calculate conservative HSP scenarios.

## 2034–2035 | Age 26–27

Preferred Japan transition window if opportunity and score profile are strong.

Maintain lawful residence/work status and build Japanese workplace capability.

## 2035–2036 | Age 27–28

Build Japanese career, maintain HSP profile, document everything, and assess PR timing.

If the 80+ fast-track route is legally and factually satisfied, the 1-year PR framework may be relevant.

## By 27–29

Target end state:
- European Bachelor's
- ≥3 years European professional experience
- Japanese IT employment
- strong Cloud/DevOps/SRE/Platform profile
- N2/N1 Japanese
- HSP 80+ target where achievable
- PR application/approval window subject to current legal requirements.

## Buffer rule

This timeline is aggressive. A delayed degree, unemployment, weak finances, or a weak Japanese job offer can move the dates.

Do not respond by compressing learning recklessly. Protect the highest-value sequence: degree + professional experience + technical specialization + Japanese + HSP eligibility.
