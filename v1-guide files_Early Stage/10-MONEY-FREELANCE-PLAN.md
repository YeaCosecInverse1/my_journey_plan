# MONEY + FREELANCE STRATEGY

## Current financial philosophy

The user is currently financially dependent in Bangladesh while preparing to leave for higher education.

The goal is not to force freelancing into the center of the career.

## Income hierarchy

1. Build skill.
2. Produce proof.
3. Sell a small useful outcome.
4. Deliver reliably.
5. Build reputation.
6. Increase price.

## Do not set skill phases by income

Wrong:
"Learn Docker → earn ৳50k."

Better:
"Learn Docker → deploy applications reliably → offer Docker/deployment services → see whether the market pays."

## Earliest commercial skills

When independently competent:
- Python automation
- file/data processing
- CSV/JSON work
- API integrations
- small backend tasks

Later:
- Dockerization
- Linux deployment
- AWS deployment
- CI/CD
- Terraform
- monitoring

## First income milestones

৳1: someone voluntarily pays for your useful work.

৳5k: proof of commercial usefulness.

৳10k/month: repeatability begins.

৳20–30k/month: meaningful side income.

৳50k+: meaningful financial leverage.

These are milestones, not promises.

## Freelance rule

Start when you can independently deliver one small service.

Do not start merely because you are bored or because you need money immediately.

## What freelancing is for

- optional income
- practical problem solving
- customer communication
- portfolio evidence
- confidence
- savings

## What freelancing is NOT for

It is not the replacement for the European full-time experience target.

The career engine remains:
Bachelor's → internship → European employment → 3+ years experience → Japan.

## Bangladesh savings principle

Any legitimate side income before Europe should first strengthen:
- emergency buffer
- education/departure fund
- application costs
- laptop/technical infrastructure
- visa/travel reserve

Avoid lifestyle inflation.
